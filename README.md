# Mononote

Releases of **Mononote**, a personal music player for PC and Android.

## Download
Open the [latest release](https://github.com/SmallestDev/mononote-releases/releases/latest) and download:
- `Mononote-Setup-<version>.exe` for Windows
- `Mononote-android-<version>.apk` for Android

## Updates
Both apps include an automatic update system.

When a new version is released, the apps check for updates when launched and download the latest version automatically. On Windows, an update found when you open Mononote is installed right away and the app reopens by itself; one found later is installed while Mononote isn't in use. It is installed in the same place, so your shortcuts and taskbar pin keep working. On Android, tap "Install" when asked.

## Installation
### Windows
1. Download `Mononote-Setup-<version>.exe`
2. Run it. Mononote installs for your account only (no administrator rights needed) and adds shortcuts to a "My Apps" folder on the Desktop and to the Start menu.
3. To keep it on the taskbar, right-click the shortcut in Desktop → My Apps and choose "Pin to taskbar" (on Windows 11: "Show more options" → "Pin to taskbar").

> Windows may show "Windows protected your PC" because the installer isn't signed. Choose **More info** → **Run anyway**.

To uninstall, open Settings → Apps → Mononote. Your library is kept, so reinstalling picks up where you left off.

`Mononote-windows-<version>.zip` is used by the automatic updater. You don't need to download it.

### Android
1. Download `Mononote-android-<version>.apk` on your phone
2. Open it and allow installing from this source once
3. Sign in with the same account you use on your PC

## Notes
The phone app works on its own. The PC app is only needed for PC features such as sending files from your PC to your phone.

If you encounter a problem, please report it so it can be fixed in a future update.
